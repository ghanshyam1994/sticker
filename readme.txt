Automatic 10% discount on five or more non-sale product units tagged sticker.

== Description ==

Author: ghanshyam saini.

Uses native WooCommerce virtual coupons to discount eligible products only, preserving product prices and displaying a separate discount. Supports guest customers, classic checkout, Checkout Blocks and HPOS-compatible order metadata.

See README.md for assumptions, setup, hooks, metadata, test instructions and exact development versions. See TEST-RESULTS.md for verified coverage.

== Installation ==

1. Install and activate WooCommerce.
2. Upload this plugin and activate sticker.
3. Tag eligible products with the product tag slug sticker.
4. Add at least five non-sale eligible units to the cart.
